# NewsEra– News Aggregation Web Application

A simple and responsive News Aggregation web application built using React.js. It allows users to browse the latest news from different categories using a REST API.

## Features

- Latest news articles
- Category-based news browsing
- Infinite scrolling for loading more articles
- Reusable React components
- Responsive and modern UI
- Loading spinner while fetching news
- User-friendly interface

## Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Bootstrap
- REST API

## How to Run the Project

1. Clone the repository:
  git clone https://github.com/saurabh-2414/NewsEra-News-Aggregation-Web-Application/

2. Open the project folder in Visual Studio Code.

3. Install the required dependencies:
    npm install

4. Start the development server:
   npm start

5. The application will open in your browser.
   API Used
   
News API

The application uses a REST API to fetch and display news articles dynamically.
